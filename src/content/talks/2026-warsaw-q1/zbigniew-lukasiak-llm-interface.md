## Abstract

Composed LLM apps fail when components violate contracts. The fix: a unified interface for LLM and code, so you can harden boundaries into deterministic code as patterns emerge. Same call site, cheap refactoring.

## Bio

Zbigniew Łukasiak has been a software developer since the dot-com era, working across startups, corporations, and academia (including PhilPapers at the University of London). He sees the same energy in LLMs that he saw at the birth of the web—and the same need for engineering discipline. He's the author of llm-do.
